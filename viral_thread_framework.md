# Viral Twitter Thread Framework

## Your Content
"I analyzed 10,000 buyside analyst writeups and here are the X things that Y"

---

## THE FRAMEWORK

### 1. HOOK (Tweet 1) — The Stop-Scroller

**Formula:** `[Credibility] + [Big Number] + [Surprising Finding] + [Promise]`

**Template:**
```
I analyzed 10,000 buyside analyst reports from top hedge funds.

[X]% of the best performers do the same [Y] things.

Here's what separates the signal from the noise: 🧵
```

**Why it works:**
- **10,000** = massive sample size (credibility)
- **buyside analyst reports** = insider access (exclusivity)
- **top hedge funds** = aspirational audience
- **X%** = specific number creates curiosity gap
- **signal from noise** = pain point for finance Twitter

**Alternative hooks:**
```
I read 10,000 investment theses so you don't have to.

The best analysts all do one thing differently.

(It's not what you think)
```

```
Most investment theses fail for the same 3 reasons.

I analyzed 10,000 reports to prove it.

Here's what the top 1% do instead:
```

---

### 2. STRUCTURE (Tweets 2-N)

**The "I Analyzed" Thread Arc:**

| Tweet # | Purpose | Example |
|---------|---------|---------|
| 1 | Hook | The big claim + promise |
| 2 | Methodology credibility | "How I did this: I scraped VIC + SumZero..." |
| 3 | Surprising stat #1 | "73% of winning picks had this in common..." |
| 4 | Insight + mini-story | "One analyst nailed TSLA in 2019 because..." |
| 5 | Contrarian finding | "Shorter writeups actually outperformed..." |
| 6 | Tactical takeaway | "If you want to write better theses, do X" |
| 7 | Visual break | Chart/table/screenshot |
| 8-10 | Additional findings | One insight per tweet |
| 11 | Self-deprecating or human moment | "I expected to find X, but was wrong about..." |
| Final | CTA + bookmark prompt | "Save this thread. I'm sharing the full dataset soon." |

---

### 3. ENGAGEMENT MECHANICS

**Open Loops (keep them reading):**
- End tweets with "But here's the thing..." or "That's not even the craziest part:"
- Tease next insight at end of each tweet

**Specificity Signals:**
- Use exact numbers: "73%" not "most"
- Name-drop real funds/analysts (if public info)
- Reference specific tickers that hit

**Pattern Interrupts:**
- Tweet 4 or 5: Personal story or admission
- Tweet 7: Image/chart (visual break)
- Final tweet: Direct ask ("RT if useful")

**Controversy Injection:**
- Challenge conventional wisdom: "Long writeups don't predict returns"
- Call out bad practices: "Stop doing X—it doesn't work"

---

### 4. TIMING & POSTING

- **Best times:** 8-10am EST (market open crowd) or 7-9pm EST
- **First 30 min critical:** Reply to every comment
- **Quote-tweet your own hook** 4 hours later with new angle

---

### 5. PROMPT TEMPLATE FOR GENERATION

```markdown
Write a viral Twitter thread using this framework:

CONTENT SOURCE: [Your findings/data]

THREAD STRUCTURE:
1. HOOK: Use "I analyzed [number] [thing]" format with surprising stat
2. CREDIBILITY: Brief methodology (1 tweet)
3. FINDINGS: 5-7 insights, one per tweet, most surprising first
4. PROOF: Include specific examples, numbers, names where possible
5. HUMANITY: One tweet that shows personal take or surprise
6. CTA: End with save/bookmark prompt + tease future content

STYLE RULES:
- Max 240 characters per tweet (leave room for engagement)
- Start each tweet with the insight, not preamble
- Use numbers and specificity over vague claims
- One idea per tweet, no multi-point tweets
- Contrarian > Obvious
- End 3+ tweets with open loops

AVOID:
- Generic advice everyone knows
- "Here's a thread on..." openings
- Asking for engagement ("like if you agree")
- More than 12 tweets total
```
